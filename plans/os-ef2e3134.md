# Plan: next: expose verdict defer in the registry (os-ef2e3134)

`seed verdict defer` is the human-verdict deferral (`next/spec/verdicts.md`,
"The human verdict is a deferral fact"): the verifier's own act naming the
rubric items it could not judge, appended as `verdict.deferred`. The
dispatcher in `next/cmd/seed/verdict.go` routes it, but the verdict
group's registry row (`next/cmd/seed/catalog.go`) lists `receipt, render,
check, traces`, and the usage line speaks the same four words. The
registry is the one source the machine protocol derives its method set
from (plans/os-b55e5647.md D2; III.I: the machine surface exposes the
CLI's verbs with identical semantics), so `seed serve` cannot reach the
deferral, and a lane working over the machine surface has no way to route
a low-confidence item to a human. os-7fc2ca38's decision log recorded the
gap and left it for its own card; this is that card.

Design authority is `SEED-NEXT.md` §II.8 (low-confidence items route to
human verdict) and III.I (one surface, one semantics), plus
plans/os-b55e5647.md D2 (the catalog is the verb table and the drill holds
its rows to the usage vocabulary in both directions). No verb changes
behavior; no conformance row changes status.

## Design decisions (binding for this task)

- **D1. One row, one word, no new semantics.** Add `defer` to the verdict
  group's `Subs` and to the usage line the dispatcher speaks, in the
  order the dispatcher's switch reads (`receipt, render, defer, check,
  traces`). The verb's flags, refusals and postures are untouched;
  `serve` dispatches `verdict.defer` to the same function the CLI does,
  which is what III.I's "identical semantics" means.
- **D2. The existing drill is the gate; one drill names the method.** The
  registry-mirrors-the-vocabulary drill already fails on a row without a
  dispatcher case or a case without a row, so the change cannot land
  half-done. One added drill asserts what the gap cost: `verdict.defer` is
  in `serve --list`'s methods, `Resolve("verdict.defer")` maps to the
  verdict group with the `defer` argv prefix, and the machine surface's
  usage refusal for `verdict.defer` with no flags names the verb's own
  flags rather than "unknown subverb".
- **D3. Records only.** The decision log gains the closing line under
  os-7fc2ca38's section pointer; the progress file gains one line; no
  spec text changes, since `verdicts.md` already documents the verb and
  the machine surface's method set is derived, never listed.
