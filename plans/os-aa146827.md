# Plan: next Phase 1.1 — event model, JCS canonicalization, Ed25519 (os-aa146827)

Implements [`docs/next-build-plan.md`](../docs/next-build-plan.md) Phase 1
item 1: `next/internal/event`, the wire-level core every later package
consumes. Design authority: [`SEED-NEXT.md`](../SEED-NEXT.md) Part II §1 and
Appendix B; normative encodings: [`next/spec/protocol.md`](../next/spec/protocol.md)
(JCS canonical form, lowercase-hex SHA-256 chain hash, lowercase-hex Ed25519
signatures, the `{"event": …, "sig": …}` ledger record, actor fingerprints,
the empty-hash genesis rule). Conformance: III.A — events carry the required
fields and the signature covers the canonical form including `prev`.

## Steps

1. **Types.** `event.Event` with exactly the canonical fields (`v`, `ts`,
   `actor`, `verb`, `subject`, `payload`, `prev`; payload as arbitrary JSON
   object) and `event.Record` (`{Event, Sig}`), (de)serializing the wrapper
   per the spec. Constant `event.EmptyHash` (SHA-256 of zero bytes) for the
   genesis `prev`.
2. **Canonicalization.** `Canonical()` producing RFC 8785 (JCS) bytes of the
   event object via `github.com/gowebpki/jcs` (first module dependency,
   logged in the decision log); `Hash()` = lowercase-hex SHA-256 of those
   bytes.
3. **Keys and signatures.** Ed25519 via `crypto/ed25519`: `Sign` (128-char
   lowercase-hex `sig` over the canonical bytes), `Verify`;
   `Fingerprint(pub)` = lowercase-hex SHA-256 of the raw 32-byte public key;
   OpenSSH ed25519 key loading (public and unencrypted private, via
   `golang.org/x/crypto/ssh`; encrypted keys refuse with a clear message).
4. **Tests** (table-driven; conformance comments citing III.A): canonical
   bytes match known JCS vectors (field ordering, string/number encoding,
   UTF-8); hash and signature round-trips; any canonical-field mutation
   breaks hash and signature; wrapper parse tolerates field order and
   whitespace but recomputes canonical bytes; fingerprint and empty-hash
   vectors; OpenSSH fixture keys load to the same raw key and fingerprint.

## Acceptance Criteria

- `event.Event` carries exactly the spec's canonical fields; `Canonical()`
  is RFC 8785 output byte-for-byte (vector-tested); `Hash()`/`Sign()` encode
  lowercase hex at the spec'd lengths (64/128).
- Signature verification fails for any mutation of any canonical field
  (including `prev`), and for a signature by a different key.
- `Record` round-trips the `{"event": …, "sig": …}` wrapper; verification
  recomputes JCS bytes from the parsed event, never trusting stored bytes.
- OpenSSH ed25519 public and unencrypted private keys load; fingerprints
  match the raw-key rule; the OpenSSH display form appears nowhere.
- Coverage gate (≥90% on `next/internal/...`) holds; `make check` green.
