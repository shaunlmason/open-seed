# Plan (next): mark III.P row 1 partial until the first seed/v* release (os-53650015)

Card os-53650015, tier trivial, filed by a read-only review of the tree
at bfa01638. `next/spec/conformance.json` pillar P row 1 carried status
`met` beside a note naming an unclaimed residual: the criterion's first
clause, "clone-and-init adoption from tagged releases", is not met
because no `seed/v*` release has been cut (the dispatch-only workflow
`.github/workflows/seed-release.yml` has never run). The same shape is
recorded as `partial` elsewhere (III.C row 4: met core plus a named
remainder). `seed doctor` reads the status field, so its outstanding
count was one short and the Phase 13 exit line's "Part III complete"
would have included an unmet clause.

The tier is trivial, but the receipt gate (D3, D4.5) demands a merged
plan at the merge base of every `seed/<id>` branch whatever the card's
tier (memory/LEARNINGS.md, os-6e37b10e). This plan exists so the task
PR, #340, can carry a receipt. It records the decision the card and the
review of #340 already settled, and asks for nothing beyond it.

## Design decisions (binding for this task)

- **D1. Flip, do not split.** The card offered two remedies: flip P.1
  to `partial`, or split the release clause into its own row. Flipping
  keeps the charter's row set unchanged (Part III rows are the
  charter's, not the implementation's to add to) and matches the
  precedent III.C row 4 sets for a met core with a named remainder.
- **D2. The residual has one owner.** The note names the unmet clause
  and the step that closes it: promotion section 5 step 2 cuts the
  first `seed/v*` release. No new card, no new phase item.
- **D3. One statement of what remains.** The Phase 12 exit record in
  `next/docs/progress.md` and the promotion packet in
  `next/docs/promotion.md` are the sources the conformance table
  transcribes, so they change with it (review finding on #340). The
  generated report is regenerated, never hand-edited.
- **D4. The build plan's exit line is reconciled, not contradicted.**
  `docs/next-build-plan.md` is the binding authority and its Phase 12
  exit line reads "III.P complete"; a partial P.1 would contradict it
  (review finding on #360). The line gains the same shape the build
  plan already gives III.C row 4 in section 3: it names row 1's
  tagged-release clause as the one residual, owned by section 5 step
  2, walked partial by the Phase 12 exit record. Phase 12 stays
  closed; nothing else on the line moves, and no criterion is
  relaxed silently.
