# Plan: seed — untrack the next/seed build artifact (os-a487b3b5)

The card: *"next/seed is a tracked binary that go build ./... overwrites,
forcing a git checkout -- next/seed incantation before every commit in
every worktree where a build ran … Untrack it: remove from the index,
add to .gitignore, point the Makefile/check-next at an untracked output
path, update any docs or flavors that reference the tracked path. Zero
behavior change; deletes a permanent landmine."* Agent-ergonomics
program item 4.

## What the tree actually shows

Measured, not assumed:

- **`next/seed` is a 12 MB executable tracked in git**, last touched by
  #137 (the reconciliation chain) and before that by #135 (the verdict
  pipeline): it was committed as a side effect of building, twice, and
  never on purpose.
- **The build plan already names the output path**: "During incubation
  it is built into `next/bin/` and invoked explicitly (`go run
  ./next/cmd/seed`, or `next/bin/seed`), never installed on PATH"
  (docs/next-build-plan.md §0), and `next/.gitignore` already ignores
  `bin/`, `var/` and `coverage.out`. What it does not ignore is a binary
  dropped at the module root, which is what `cd next && go build
  ./cmd/seed` produces.
- **`make check` builds nothing to a path.** `check-next` runs `go build
  ./...`, which with a multi-package pattern discards every executable;
  the card's "point the Makefile/check-next at an untracked output path"
  has nothing to point, and `next/cmd/covergate` builds no binary
  either. The landmine is armed by a hand-run `go build ./cmd/seed`
  from `next/`, not by the gate.
- **Nothing references the tracked path.** No Makefile target, script,
  flavor or doc outside `next/docs/` names `next/seed`; the receipt
  runner invokes the engine, not this binary.

## Design decisions (binding for this task)

- **D1 — untrack and ignore; change no build.** `git rm --cached
  next/seed`, and `next/.gitignore` gains `/seed` beside `bin/`, with
  the comment saying why (a `go build ./cmd/seed` run from the module
  root lands here). The binary stays on disk in every existing checkout
  as an ignored file, so no worktree breaks, and `git status` stops
  reporting it.
- **D2 — no Makefile change.** `check-next` produces no binary, so
  "point it at an untracked output path" is already true of it; adding
  an output path would be a behavior change the card says to avoid.
- **D3 — scope guard.** No change under `next/cmd/**`, no new `bin`
  target, no flavor edits: none references the path.

## Steps

1. `git rm --cached next/seed`; `next/.gitignore` gains `/seed` with
   its comment.
2. `next/docs/decisions.md` records D1 and D2 in two sentences.
3. Receipt; evidence; review.

## File Scope

- `next/seed` (index removal only), `next/.gitignore`,
  `next/docs/decisions.md`
- `receipts/os-a487b3b5.json`

Nothing else: not the `Makefile`, not `next/cmd/**`, not `flavors/**`.

## Acceptance Criteria

**Boundary set (new, shown working):**

1. `git ls-files next/seed` prints nothing on the task branch, and
   `git check-ignore -v next/seed` names the `next/.gitignore` rule.
2. From `next/`, `go build ./cmd/seed` leaves `git status --porcelain`
   empty (the produced binary is ignored), and `go build ./...` still
   produces nothing on disk.
3. `make check` is green and its output is byte-identical to the base
   branch's (the flavor-test core-gate-independence check diffs it).
4. The diff touches exactly the files in scope.

**Retention set (existing, shown unharmed):**

- `make check` stays green with byte-identical output (AC3), so the
  flavor-test core-gate-independence diff sees no change.
- `go build ./...`, `go vet ./...` and the full suite under `next/`
  pass exactly as before: no source file changes.
- Every existing worktree keeps its on-disk `next/seed` as an ignored
  file; no worktree, script, flavor or doc breaks, because none
  references the tracked path.

## Validation Commands

- Boundary: `git ls-files next/seed` (prints nothing) and `git check-ignore -v next/seed` (names the rule) and `cd next && go build ./cmd/seed && git status --porcelain` (prints nothing)
- Retention: `cd next && go build ./... && go test ./... -count=1` and `make check`
  (exit checked separately from any pipe).

## Expected diff shape

One index deletion (`next/seed`, 12 MB, no content change on disk),
two lines in `next/.gitignore` (the rule and its comment), and a short
note in `next/docs/decisions.md`. No Makefile, `next/cmd/**`,
`flavors/**` or script edits; no source change; no deletions of tests.
