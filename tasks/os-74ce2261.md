Found while walking charter III.G row 10 ("evidence, receipts, and verdicts are queryable by contract, actor, time, and outcome") for the Phase 10 exit record (os-a026f5ea). The SQLite cache projection (next/spec/projections.md; next/internal/project/cache.go) answers contract, actor and outcome: the contracts table carries subject, position, verb, actor and the payload verbatim, and contract_state carries the verdict columns. It answers TIME only by position, which is order, not a clock: no table carries the event's ts. The row is therefore recorded UNMET at the Phase 10 exit, and this card closes it.

Scope: a ts column on the cache's contracts table (and any per-fact table whose rows are events), filled from the event envelope's ts, at the next cache generation with the stamp discipline projections.md states; the projection's spec sentence; a drill querying by a time range against a fixture chain. No new verb, no transition row, no protocol version. Change nothing about what the cache is (a registered, byte-identical projection). Trivial tier: additive column, no behavior change to any existing reader.
