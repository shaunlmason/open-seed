Agent-ergonomics program, item 2. The affordance principle (one rule set, two consumers: enforcement at the boundary, advertisement in the envelope, drift a named bug class — proven in next/** 8.1/8.2) applied to the v1 task CLI agents drive daily: every task-verb response lists the card's legal next transitions plus the flags each requires (review requires attached evidence; blocked requires --blocked-on; an unplanned above-L1 claim authorizes planning only), computed from the same transition tables that enforce them. Refusals teach the legal spelling: plan-unblock refused entry-string forms three times before --pr N was found, and lease-renew on a review-state card said invalid_transition with no hint that review-state cards hold no lease — those two scars are the seed test corpus; one retry should converge. Economy doctrine: optimize the success path for brevity (bare names) and the failure path for pedagogy (one sentence naming the spelling). Drift test class per the 8.2 precedent: an advertised transition refused at the same card state is a failing test.
