A relative markdown citation naming a path the tree does not hold renders broken and nothing catches it. A sweep on 2026-09-04 found 570 relative links across the repository's markdown and 7 that do not resolve, in documents the conformance table itself cites as evidence: docs/CONTRIBUTING-AGENTS.md wrote four targets root-relative from inside docs/ (build-plan.md twice, design-options.md, research/10-org-control-planes.md), and III.Q row 5 cites that file as the authority order's evidence; next/spec/requests.md cited a classification.md that has never existed (the citation entered with #270, and the reference-exemption grammar it names is stated in packets.md); plans/os-2e34f66a.md cited obligations.md relative to plans/. The seventh is a false positive: a regex inside a code span in docs/research/inspirations/05-skills-packaging.md. Skipping code spans and fenced blocks is therefore part of this item, not a refinement of it. The six real ones are fixed in commit f320743 on branch claude/cleat-seed-next-eval-535lvf, so the tree is at zero and this gate lands green with no baseline.

Source: the doc-citations gate in svetdev/cleat (MIT), evaluated 2026-09-04. The rest of that tool was declined, and the rejection is recorded with its reason per III.Q row 4: cleat's enforcement rests on local agent hooks plus CODEOWNERS, which sit inside the blast radius the charter's II.2 compromised-implementer invariant assumes, and Seed already holds the ratchet layer with covergate, perfgate and the protected surface. Its doc-citations gate is the one part with no counterpart here. Adopting the idea rather than the tool also keeps the no-new-toolchain bound: cleat is Python, next/** is Go.

Expected shape, for the plan to settle: a citation stage inside `seed docs check` (internal/docs), so the make check line that already runs `seed docs check --root ..` gains it with no new command. internal/promotion.Check is the prior art to generalize rather than copy: it holds one document's citations to the tree in one machine-readable shape, and os-98ce6f8a's learning names the trap it already handles, that filepath.Join cleans `..` into a read outside the tree the gate promises. The generalization walks the markdown set under root, extracts relative link targets outside code spans and fenced blocks, resolves each against its containing file's directory, confines the result under root, and fails naming file, line and target.

Bounds: no new dependency and no new toolchain; output byte-stable, because the flavor-test core-gate-independence check diffs make check's output; anchors (#fragment) stripped and not verified in this item; external URLs out of scope, since resolving them needs the network and the gate must stay offline and deterministic; the v1 template instantiation must stay green, so the stage self-skips exactly as check-next does when next/ is absent. Tier: standard. Not conformance-blocking: III.Q row 3 is already met by the generated-doc drift check, and this hardens past it. Build plan section 3 backlog, a true extra.
